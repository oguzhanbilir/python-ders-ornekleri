# Python ders örnekleri

Derslerde kullanmak için yazdığım küçük Python ve tkinter uygulamaları. Hepsi kısa; okumak ve üzerinde oynamak için hazırlandı.

| Klasör | Ne yapar |
|--------|----------|
| `calculator` | tkinter ile basit hesap makinesi |
| `fastWriteTest` | Yazma hızı ve doğruluk testi |
| `matMemoryGame` | 4x4 hafıza oyunu: her işlemi sonucuyla eşleştir |
| `QRCodeCreator` | Metni veya bağlantıyı QR koda çevirip PNG olarak kaydeder |
| `rockPaperScissors` | Taş kâğıt makas, 5 puana ilk ulaşan kazanır |
| `youtubeVideoLoader` | YouTube videosunu seçtiğiniz kalitede indirir |

## Çalıştırma

Python 3 yeterli; tkinter onunla birlikte gelir.

```bash
cd calculator
python calculator.py
```

`QRCodeCreator` ve `youtubeVideoLoader` için önce kendi klasörlerinde `pip install -r requirements.txt` çalıştırın. Her klasörde biraz daha ayrıntı içeren bir README var.
